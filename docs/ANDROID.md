# 最后核心 Android 离线版

版本：0.3.0-offline，版本号 3。横屏、纯离线、本地存档。

## 安装与升级

安装 `LastCore-Android-v0.3.0-offline.apk`。包名与旧版一致：`com.xizhi3002.lastcore`，沿用同一调试签名，可覆盖升级保留存档。不要先卸载旧版，卸载会删除存档。

最低 Android 7.0（API 24），支持 ARM 32/64 位。此包仍为调试签名开发版，尚未上架商店。没有互联网权限、账号登录、在线排行榜或跨设备同步。

## 操作

- 默认完整显示地图；顶栏和底栏缩小，左侧半透明面板展示建筑属性和操作。
- 顶栏“暂停/继续”随时可用。默认 **0.5 倍速**，可直接切换 1 倍、2 倍。
- 蓝图可横向滚动。向上拖出蓝图进入战场，或轻点蓝图再轻点目标格；预览会显示射程、目标格和移动痕迹。
- 左侧选择“确认放置”才扣预算，选择“取消”不产生任何建筑或扣费。无效地格标红且不能确认。
- 轻点已有炮台查看射程、统计和目标优先级。波间可选择移动、拆除，均需再次确认；移动前原建筑保留。
- 石墙、栅栏、地雷和凝滞地场也遵循确认流程；不能封死任何入口。
- 波间暂停仍可布阵。选择蓝图会进入编辑状态，停止自动开波倒计时，完成后点击“下一波”开始。
- 战斗中暂停可以查看信息，但不能改变阵容。
- 没有部署预览时，单指拖动平移；双指缩放。点击“全图”恢复完整地图。
- 高亮当前/下一波出怪点和核心，沿路线移动的箭头指向核心；不显示下一波未启用入口的路线。
- 系统返回键优先取消部署预览，然后关闭弹窗或打开菜单。切到后台自动保存并暂停。
- 战斗中保存后重新打开会恢复到本波开始前；关闭游戏没有离线收入。

## 开发

Godot 4.5.2 stable；OpenJDK 17；Android Build Tools 35.0.0 和 Android 35 平台。字体使用 SIL OFL 授权的 Noto Sans SC。

```powershell
.\build-android.ps1 -Godot 'Godot可执行文件路径' -Template 'android_debug.apk路径'
godot --path . -- --mobile --test
godot --path . --script res://tests/mobile_smoke.gd -- --mobile --test
```

在 Godot 编辑器设置中配置 Android SDK、Java SDK 和调试签名。`--test` 使用独立测试存档，截图与报告位于 build/。正式商店发行仍需发布签名与真机兼容性验收。
