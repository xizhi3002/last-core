# 最后核心 Android 开发预览版

版本：0.2.0-mobile-preview。横屏、离线、本地存档。与桌面版共用战斗规则，未接入 Steam 或手机应用商店服务。

## 安装

把 `LastCore-Android-v0.2.0-preview.apk` 发送到安卓手机，点击文件安装。如系统要求，允许当前文件管理器安装应用。安装后打开“最后核心”。

构建最低要求为 Android 7.0（API 24），支持 ARM 32 位和 64 位设备；图形使用 OpenGL Compatibility。当前 APK 为调试签名开发预览包，不是商店正式发行包。升级应保留相同包名和签名；卸载会清除应用内存档。

包名：`com.xizhi3002.lastcore`。本地玩法无需联网，APK 未申请互联网权限。手机存档与电脑存档独立，暂不提供跨设备同步。

## 手机操作

- 横屏使用。主菜单选择“部署新防线”，选地图和六种蓝图后开始。
- 战场底部蓝图栏可以横向滑动，选择后轻点空格建造。轻点已有建筑可以查看属性和调整选敌优先级。
- 单指拖动平移棋盘，双指捏合缩放；也可以点“＋”“−”缩放和“居中”回到核心。小地图支持轻点定位。
- “拆除”模式下轻点建筑即可拆除；“移动”模式下先点建筑，再点目标格。建造规则、预算和封路检查仍然生效。
- “作战”面板提供 1/2/3 倍速、编辑、基础布阵、路线、波次挑战及自动奖励设置。
- 开战按钮在战斗中变成暂停/继续；周期结束时可以进入奖励和商店。
- 页面与弹窗内容过多时可滑动查看；手机系统返回键可关闭弹窗或打开暂停菜单。
- 切到后台会保存波前/波间进度并暂停。回到前台后手动继续；关闭游戏不会产生离线收益。

## 源码与构建

Godot 4.5.2 stable，OpenJDK 17，Android SDK Build Tools 35.0.0、Platform Tools 和 Android 35 平台。使用官方 `android_debug.apk` 模板导出，不依赖 Gradle 自定义构建。

先在 Godot“编辑器设置 → 导出 → Android”配置 Java SDK、Android SDK 和调试签名。模板位置在 `export_presets.cfg` 中，也可通过下面脚本覆盖：

```powershell
.\build-android.ps1 -Godot '你的Godot路径' -Template '你的android_debug.apk路径'
```

直接导出：

```powershell
godot --headless --path . --export-debug Android build/LastCore-Android.apk
```

在电脑上预览手机版：

```powershell
godot --path . -- --mobile --test
godot --path . --script res://tests/mobile_smoke.gd -- --mobile --test
```

`--test` 使用独立测试存档；测试可能写入截图和报告到 `build/`。手机自动检测 Android 平台，无需启动参数。字体采用 SIL OFL 1.1 授权的 Noto Sans SC，许可证随源码和资源附带。

正式发行仍需要发布签名管理、应用图标与商店素材验收、真实手机兼容性测试及相应商店上架流程。本次未创建商店发布密钥，也未上架商店。
