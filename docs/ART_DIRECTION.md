# 最后核心 / 视觉与资产记录

版本：lc-0.1.0-r1；制作日期：2026-10-10。

AI 编写的原创程序绘制美术，无第三方贴图：六边形中央核心、六/八类炮塔、机械虫群、晶体岩块、栅栏、陷阱、射线、冲击圈、菜单轨道图案、战区小地图和 SVG 图标。源文件为 scripts/board.gd、scripts/main.gd、assets/icon.svg。所有按钮、文字、选择框和滑条均为 Godot 真实 Control 控件。

色板：底色 #09131e，战场 #10202b，薄荷绿 #6ce5c5，警戒玫红 #ef7982，资源金 #ebc683，辅助蓝灰 #8597a9。四方向分别用绿、琥珀、紫、粉标色；箭头与格数辅助识别，非单靠颜色传达。

炮台在网格内占 64% 直径；核心 2×2 或 3×3，和地图几何中心一致。所有绘制使用矢量几何，缩放不依赖位图，炮塔朝向跟随目标。敌人轮廓、尺寸及颜色标识类型。血条和范围圈动态绘制。表现射线限制 180 条；停止绘制特效不改变模拟伤害。

字体使用 Windows 自带 Microsoft YaHei UI / Microsoft YaHei，通过 SystemFont 调用而不打包字体文件。其他平台需要安装支持简体中文的字体。声音是本项目运行时合成的短正弦提示音，没有外部音频素材。

Steam Content Survey：按最终实际构建申报 AI 在开发阶段参与生成的预生成美术、UI 视觉和设计内容；没有运行时大模型调用。不要把这里的开发说明替代 Steam 后台正式申报。
